Shiplog

Support

Shiplog keeps a ship's log for your code: your commits, merges and CI weather from GitHub, written up each day, with room for your own notes. It's for iPhone and iPad. There's no account and nothing to sign in to.

Get help

Email matt.hovis@icloud.com with what happened, what device you're on, and which repository you were looking at if it's public. Bug reports, ideas and questions are all welcome.

Common questions

  • Do I need a GitHub token? Not for public repositories: their name is enough. A token lets Shiplog read private ones, and raises GitHub's limit from 60 requests an hour to 5,000. A fine-grained token with read-only Contents, Pull requests and Actions is all it needs. Add it in the Harbour, under GitHub lookout.
  • It says "Out of GitHub requests for now". Without a token GitHub allows 60 requests an hour, and a first sail can use a dozen or more per repository. Shiplog says when the limit resets; a token lifts it.
  • It says it couldn't find my repository. Check it's written as owner/repo. If it's private, add a token that can see it.
  • What do ports, squalls and whales mean? A port is a merged pull request, a squall is CI turning red, and the white whale is the one stubborn bug you're chasing. The Harbour's articles explain every word, and Easier reading & fittings › Plain words swaps them for ordinary ones.
  • Is my log backed up? It lives on your device. The Harbour can back up every ship to a file, export the whole log as Markdown, and, where iCloud is offered, keep your own words on your other devices.
  • Does Shiplog collect any data? No. See the privacy policy for the full answer.
